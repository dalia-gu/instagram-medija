# instagram-medija

Tiltas tarp kompiuterio ir Instagram.

Instagram API negali paimti failo iš kompiuterio — jam reikia viešos nuorodos.
Šis aplankas yra vieša GitHub saugykla su įjungtu GitHub Pages, tad kiekvienas
čia įkeltas failas iškart turi savo adresą internete:

    https://dalia-gu.github.io/instagram-medija/<failo-vardas>

## Taisyklės

- Čia dedama **tik tai, kas ir taip bus paskelbta viešai** — Instagram įrašų
  paveikslėliai, karuselių skaidrės, video.
- Jokių klientų nuotraukų, vardų, dokumentų ar bet kokios konfidencialios
  medžiagos. Saugykla vieša — ją mato visi.
- Paveikslėliai JPEG formatu, santykis 4:5 (1080 × 1350) Instagram įrašams.
- Karuselės skaidrės numeruojamos: `tema-01.jpg`, `tema-02.jpg` ...

## Kaip naudojama

1. Failas nukopijuojamas į šį aplanką
2. `git add . && git commit -m "..." && git push`
3. Po kelių sekundžių failas pasiekiamas per nuorodą ir Instagram API gali jį paimti
